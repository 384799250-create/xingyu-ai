成本分析口径
Token 按服务商返回的输入、输出用量分别计算；缓存价留空时，全部输入使用普通输入价，不重复计算推理 Token。配置缓存价但接口未返回缓存数量时，金额待核对。Token 失败但已返回完整用量时仍计算参考成本，拟收费排除失败。旧 Token 记录无法区分内部重试；费用试算用于核对成本，不作为真实账单。
图片按成功返回的图片张数计算，一次返回多张分别计价；现有账本未记录尺寸，暂按模型统一价格。语音按成功合成字数计算，含标点、空格和换行，每个 Unicode 字符计一字；缓存播放不重复计入。媒体重试及音色试听计算成本、拟收费为零。接口成功不等于微信送达。
超时、结果未知及用量缺失单独标记。仅当成本和拟收费都完整时，才计算该笔参考差额；差额未包含服务器、支付和其他经营成本。本页按当前价表做参考分析，不会修改已锁价消费。正式价格在“计费价格”管理；上线前的模拟记录收在“历史资料 → 历史模拟余额”。
