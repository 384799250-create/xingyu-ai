需要另外下载一个聊天 App 吗？

不用另外安装聊天 App。先在网页注册并创建 AI，按页面提示完成微信扫码和连接，之后就能在微信里聊天与打开设置。

这是我自己的 AI，还是大家共用一个？

开通后连接的是分配给你的独立应用，有自己的设置、人格、记忆和聊天空间。其他成员的内容不会显示在你的个人设置中。

每日赠送的星币会累计吗？

不会。每日赠送面向已完成 AI 开通、拥有星币账户的新老用户。同一企业成员账户每天一份，跨应用不重复发放。公测期间每天赠送 1000 活动星币，当天未用完的部分于北京时间次日 0 点清零。充值与原有长期余额不受这个到期规则影响。

我想修改性格、声音或记忆，怎么操作？

在自己的微信 AI 对话中发送 我要设置，打开返回的个人设置链接，就可以调整相关内容。链接仅供本人使用，请勿转发。更多说明可查看使用说明。
