# 星屿 AI · Xingyu AI

微信里的 AI 伙伴：独立应用、可编辑人格、记忆、语音与图片、主动陪伴，以及完整的网页账号、管理后台、应用开通和星币计费系统。

本仓库是项目完成后的公开源码归档，整理日期 **2026-11-08**。从当日线上源码只读提取网站、后台、服务端与企业运行时，并合入本地微信小程序源码。密钥、生产配置及用户/支付数据不在仓库内，部署标识使用示例值。

## 模块

- 网站：首页三主题轮播、使用说明、邮箱注册登录、创建 AI 与微信扫码开通。
- 新手引导：等待分配时显示五步截图；扫码后进入伙伴界面，提示约 5 秒加载；最后说明下次从微信聊天列表找到星屿。
- AI 运行时：人格与世界书、可管理记忆、语音/图片/表情、提醒、问候、免打扰和调用计量。
- 后台与服务端：多企业隔离、模板角色卡导入、应用池、热备/按需共享运行时、账号生命周期、充值和流水。
- 微信小程序：保留原生设置、手动保存及合成测试；该子项目已暂停，相关入口默认关闭。
